## Описание проекта

Данный проект представляет собой планировщик задач, созданный для автоматизации управления делами. Сервис позволяет пользователям хранить задачи, устанавливать даты выполнения и настраивать правила повторения.

## Файлы для итогового задания

- В директории tests находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.
- Директория web содержит файлы фронтенда.

## Выполненные задания повышенной сложности

В рамках проекта выполнены следующие задания со звёздочкой:

- Задание из урока 4: Реализована функция вычисления дат для интервалов в неделях и месяцах.
Сигнатура: func NextDate(now time.Time, dstart string, repeat string) (string, error).

- Задание из урока 7: Создан Docker-образ для приложения.

## Инструкция по запуску

### Локальный запуск

- Подготовьте файл .env с необходимыми переменными окружения:
  
- Для доступа к интерфейсу в браузере используйте адрес: http://localhost:7540 (или иной указанный вами порт).

#### Запуск тестов

- Откройте файл tests/settings.go.
- Укажите корректные параметры для подключения к вашему серверу.
- Запустите тестирование командой go test ./tests/....

### Запуск через Docker

- Соберите образ: docker build -t todo-app .
- Запустите контейнер: docker run -p 7540:7540 --env-file .env todo-app
